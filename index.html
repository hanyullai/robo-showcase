01 / SORT + REPLANTO BE VERIFIED
SCENARIO SKETCH / NOT A RECORDING

The desk reset.

Four objects. One instruction.
Then a change of plan.

“Can first. Milk next.”
“Actually, leave the milk until last.”
RECOGNIZE → ORDER → REMEMBER
What counts as a pass?

Identify all four objects from allowed visual inputs; follow the revised order, preserve completed placements, and independently verify every final placement. Full sorting plus an instruction change is not yet validated.

02 / DISTURB + RECOVERTO BE VERIFIED
SCENARIO SKETCH / NOT A RECORDING

Move the goalposts.

The target moved.
The agent has to notice.

“Pick that up.”
The object shifts before the grasp.
NOTICE → RE-OBSERVE → RECOVER
What counts as a pass?

Detect the changed object position, discard the stale target and generate a new action from current observations. Stop, resume and independent verification must still work. The recorded Stack pause/resume run below does not validate object displacement.

03 / DISASSEMBLE + REBUILDTO BE VERIFIED
SCENARIO SKETCH / NOT A RECORDING

A different kind of stack.

Take it apart.
Build it back in a new order.

“Rebuild this tower.”
“Green on top. Red in the middle.”
PLAN DEPENDENCIES → REBUILD → VERIFY
What counts as a pass?

Remove blocks in a feasible sequence, use temporary placements, and build the requested color order. Verify release, stability and final order. The existing two-cube Stack run does not validate this multi-block challenge.

These are scenario previews, not successful demonstrations. Verified recordings and their original generated policies are available in the experiments below.
