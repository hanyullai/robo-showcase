What this pilot validates
The native scene settles before the first public RGB-D observation, Viewer frame or recording. Initialization compute is accounted separately; it does not count as task progress. Model, H1, legacy controller, motion preview and continuous execution settings are unchanged; the new task asks for both parts.
This single scene is not a randomized comparison. No policies or winning trajectories are injected. The verifier reports each part and rechecks both at the end.
Trial conditions, model usage and evidence limits
The candidate version is fixed and H1 is enabled. No historical winning policy or ground-truth object state was supplied to the agent. Both parts are loaded together; this is not continuous feeding. This demonstration does not establish factory throughput, long-term success rates or real-robot reliability.
